# Full Count – Mobile Prototype (V2)

## Overview
This is a lightweight, browser‑based prototype that lets you play the **Full Count** V2 deck on a phone (or any device with a modern web browser).

- **HTML**: `prototype_v2.html` – the single‑page app.
- **JavaScript**: `app.js` – loads the card data, shows the cards, and handles power usage with the momentum‑die degradation system.
- **Data**: `cards_v2.json` – JSON representation of the 5 player cards (name, position, power, max uses, description).
- **Manifest**: `manifest.json` – makes the page installable as a Progressive Web App (PWA) so it can be added to the home screen.
- **Icons**: placeholder icons (`icon-192.png`, `icon-512.png`). Replace them with your own images if you wish.

## Gameplay basics
- Each card shows the player’s **Power**, remaining **Uses**, and current **Momentum die** (`d8 → d6 → d4 → none`).
- Press **“Use Power”** to roll a d6.
  - **Roll 4‑6** → power succeeds (the effect described on the card).
  - **Roll 1‑3** → power fails and the momentum die degrades to the next tier.
- When **Uses left** reaches `0`, the power can no longer be used.
- The log at the bottom records every roll and outcome.
